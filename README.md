# Calorie Counter

A simple web application for tracking daily calorie intake, registering food items, and monitoring a personalized daily calorie goal.

## About the Project

Calorie Counter is a web development project built with HTML, CSS, and Vanilla JavaScript, without external libraries or frameworks.

The application allows users to register food items, enter their calorie values, and track their total daily calorie intake.

## Features

- Add food items and their calorie values.
- Automatically calculate total daily calorie intake.
- Set a personalized daily calorie goal.
- Display remaining calories.
- Visualize progress toward the daily goal.
- Delete individual food items.
- Clear all food entries for the current day.
- Persist data using the LocalStorage API.
- Automatically reset the food diary when a new day begins.
- Responsive interface for desktop and mobile devices.
- Input validation for food entries and calorie goals.

## Technologies Used

- **HTML5** — Application structure.
- **CSS3** — Styling and responsive layout.
- **Vanilla JavaScript** — Application logic and DOM manipulation.
- **LocalStorage API** — Client-side data persistence.

## How to Run

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd calorie-counter
   ```

3. Open `index.html` in your web browser.

No dependencies or additional server configuration are required.

Alternatively, you can use the Live Server extension in Visual Studio Code for local development.
